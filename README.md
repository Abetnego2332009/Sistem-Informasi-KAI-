# 🚆 Sistem Informasi Kereta Api Perlanaan

Sistem Informasi Kereta Api Perlanaan merupakan aplikasi berbasis web yang dikembangkan sebagai media layanan informasi kereta api kepada masyarakat. Aplikasi ini menyediakan informasi mengenai jadwal keberangkatan dan kedatangan kereta, harga tiket, rute perjalanan, fasilitas stasiun, serta informasi operasional Stasiun Perlanaan.

Sistem dilengkapi dengan halaman administrator untuk mengelola konten dan informasi yang ditampilkan kepada masyarakat.

## ✨ Fitur Utama

### 1. Halaman Informasi Publik
- Halaman beranda informasi stasiun.
- Informasi jadwal keberangkatan dan kedatangan kereta.
- Informasi harga tiket.
- Informasi kelas tiket.
- Informasi rute perjalanan.
- Informasi fasilitas stasiun.
- Informasi jam operasional.
- Berita dan pengumuman.
- FAQ (Frequently Asked Questions).

### 2. Dashboard Admin
- Dashboard pengelolaan sistem.
- Manajemen data kereta.
- Manajemen jadwal kereta.
- Manajemen rute perjalanan.
- Manajemen harga tiket.
- Manajemen kelas tiket.
- Manajemen fasilitas stasiun.
- Manajemen berita dan pengumuman.
- Manajemen FAQ.
- Pengelolaan profil stasiun.
- Pengaturan sistem.

### 3. Informasi Stasiun
- Profil Stasiun Perlanaan.
- Informasi layanan stasiun.
- Informasi jam operasional.
- Informasi fasilitas yang tersedia.
- Pengumuman terkait layanan kereta api.

## 🗄️ Database

Nama database: `kai_perlanaan`

File database tersedia di repository:

`kai_perlanaan (2).sql`

## ⚙️ Instalasi

1. Clone repository:

   ```bash
   git clone https://github.com/Abetnego2332009/Sistem-Informasi-KAI-.git
   ```

2. Pindahkan folder project ke direktori `www` Laragon atau `htdocs` XAMPP.

3. Jalankan Apache dan MySQL.

4. Buat database dengan nama `kai_perlanaan`.

5. Import file `kai_perlanaan (2).sql` melalui phpMyAdmin.

6. Sesuaikan konfigurasi database pada `koneksi.php`.

7. Buka aplikasi melalui browser:

   ```text
   http://localhost/Sistem-Informasi-KAI-
   ```

## 🎯 Tujuan Pengembangan

Mengembangkan media informasi berbasis web yang dapat membantu masyarakat memperoleh informasi terkait layanan kereta api Stasiun Perlanaan secara lebih mudah, terstruktur, dan informatif.
